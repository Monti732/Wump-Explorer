## Инструкция по сборке и запуску

Все команды выполняются из папки `scripts/` через терминал (Git Bash или WSL).

**Сборка проекта:**
   ```bash
   ./assembly.sh
   ```
**Запуск автоматических тестов:**
   ```bash
   ./test.sh
   ```
**Ручной запуск приложения:**
   ```bash
   ./run.sh -l alice -p qwerty -a read -r A.B -v 10
   ```
